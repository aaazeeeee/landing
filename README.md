# Gilyan.exe

An original pixel-art portfolio using React, TypeScript, Tailwind CSS 4, Vite, and Motion.

Run `npm install` then `npm run dev`. Validate with `npm run build`.

Edit src/main.tsx to personalize projects, technology inventory, biography, and sample experience. Replace illustrative previews with your screenshots if desired. Add verified contributions, company names, dates, and real GitHub/LinkedIn URLs before publishing.

The contact form validates and copies a message; it does not send email. Add your contact destination or backend to enable sending. No credentials are needed for the current site.

Fonts load from Google Fonts with monospace fallbacks. Original artwork uses CSS and SVG. Reduced-motion preferences, keyboard navigation, and native project dialogs are supported.
